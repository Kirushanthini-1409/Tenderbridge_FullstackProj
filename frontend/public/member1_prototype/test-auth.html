TenderBridge – Member 1 Auth Tests

Manual test runner for Supabase auth. Fill in credentials below. All operations call Supabase directly.

⚠️ These tests call your real Supabase project. Use a dedicated test email address you control (e.g. tb-test-1@yourdomain.com). Supabase sends real confirmation emails when email confirmation is enabled.

0 · Configuration check

Verifies that assets/supabase.js has been filled in and the Supabase client is reachable.

1 · Sign up

2 · Sign in

3 · Session restore

Checks whether the session stored by the previous sign-in can be retrieved. Reload the page first to simulate a fresh load, then click.

4 · Password reset email

5 · Change password (requires active session)

6 · Sign out

7 · Error handling (wrong credentials)

Attempts to sign in with a known-wrong password. Expects a friendly error message, not a raw Supabase error object.

8 · Protected route guard

Opens business-dashboard.html in a new tab while signed out. Expect the page to redirect to #/login.
